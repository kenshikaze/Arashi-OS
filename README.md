# Arashi-OS
Arashi is WebOS which can easily booted on a web browser.<br>
-I built this project to explore libraries and expand my knowledge in Python.<br>
-This heavily relies on the library **NiceGUI**,to build and manage it's browser-based interface.<br>
*This project is still under development and only have the loading screen
and desktop with time is available*

## Features
As it is under developmet it only has:-<br>
-Boot screen
-Desktop with a taskbar
-Browser local clock

## Tech used
-Python
-NiceGUI
-JavaScript
-HTML and CSS

## Installation and Usage
You need Python installed to run Arashi-OS.<br>

1. Clone this repository:
```bash
git clone https://github.com/kenshikaze/Arashi-OS
```
2. Go into the project folder:
```bash
cd Arashi-OS
```
3. Install the requirements:
```bash
pip install -r requirements.txt
```
4. Run the project:
```bash
python main.py
```

After running it, open the local link shown in your terminal to see Arashi-OS in your browser.
